# Nexus Académico

Sistema de gestión académica para estudiantes y docentes.

## Objetivo

Desarrollar un sistema que permita organizar y administrar la información académica.

## Funcionalidades

- Gestión de estudiantes.
- Gestión de docentes.
- Gestión de materias.
- Registro de calificaciones.
- Consulta de información académica.

## Tecnologías

Por definir según los requisitos del proyecto.
